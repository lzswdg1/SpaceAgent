# SpaceAgent 液态玻璃 HTML 原型

`index.html` 是可迭代入口，配套 `pages.css`、`pages.js`；`spaceagent-complete.html` 是可单独打开的完整导出。
运行 `python3 export.py` 更新单文件导出。不需要安装依赖。

## 页面

概览、对话、项目、Agent、自动化、知识库、记忆、MCP 市场、调用追踪、模型资源、组织设置。
通过左侧导航切换，hash 路由支持浏览器前进/后退以及 `#chat`、`#project` 等直接入口。

## 交互

- 常用资源和管理功能直接显示在左侧；项目列表只在项目模式展开，离开时液态收回。
- 对话、项目都可独立收起左右栏；顶部按钮始终可恢复侧栏。窄屏改为抽屉。
- 保留项目消息，独立维护对话消息与草稿；支持新对话、示例发送、Agent/模型选择和本地附件名称展示。
- Agent 创建/编辑、自动化编辑/启停、文档添加/预览、记忆编辑/移除、工具连接演示、执行详情、模型配置、组织及成员编辑。
- 搜索、分类筛选、无结果状态、主题切换、减少动画选项。

所有数据只用于原型；项目、对话流程及 Agent 配置用 sessionStorage 模拟本标签页刷新恢复，其余列表刷新恢复初始演示数据。不会请求后端、调用模型、修改 Git、上传附件或发送邀请。

## 业务流程补全

入口仍为 `spaceagent-complete.html`，新增源码 `workflows.js`、`workflows.css`。

- 项目根目录：平级仓库/空白目录，新建/删除会话、继续加载、逻辑删除说明与失败模拟。
- 导入向导：连接 GitHub、仓库/分支选择、准备成功/失败/重试；空白目录命名与后端分配存储说明。
- 只读文件浏览：目录展开、文件代码、分支绑定、main 仅含 .gitignore 的演示与无法预览状态。
- 项目执行：询问代码/AI 编程、不同编程/评审 Agent 绑定、审批、独立评审、基线/目标说明；阻止执行中或有待处理变更时切换分支。
- 对话与项目：顶部“状态演示”选择正常、审批、断线、部分回答、失败、结果不确定；发送后展示相应状态与操作。刷新后读取本地演示状态，不发出外部请求。
- 示例回答：标题、引用、列表、表格、行内代码、代码块；用户输入仍按文本转义。
- Agent：当前配置、直接模型/ModelPool 互斥选择、Memory/RAG、工具可用性、组织修改审批、删除，不增加版本管理。

新增浏览器核验：空白目录创建到新会话；导入准备失败/重试；编程审批刷新恢复并完成独立评审；配置修改审批；Chat 断线刷新恢复；部分回答刷新与续写；分支切换/main 文件预览；390px 配置表单。修复向导递归调用命名冲突后复验，最后一轮无新增浏览器错误。

这是功能流程原型，不是后端验收：不创建物理目录、不进行 OAuth，不执行真实审批、编程、续写或删除。状态名称和操作边界仍需正式实现时逐项映射现有公开接口。

## 概览消费统计

概览保留“继续上次的工作”，移除最近活动时间线及原辅助卡片，增加 Token 消费环形图。
环形扇区表示输入/输出占比，不表示预算进度；中心为周期消费总量，下方展示输入、输出与费用示例。
进入页面自动描绘圆环，随后高光循环绕环流动；可暂停，并尊重系统和页面的减少动画设置。
支持今日/本周/本月。所有消费和费用均为明确标注的示例，不代表实际账单或模型定价。
已检查周期切换、暂停状态、深浅主题、390px 无横向溢出和 JavaScript 语法。
