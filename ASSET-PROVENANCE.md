# SpaceAgent Asset Provenance

This file records the origin and redistribution permission for repository-owned visual and design
assets. It is a factual project record, not a legal opinion.

## Brand images

- `apps/web/src/assets/branding/spaceagent-logo-deep-space-1024.png` is a project-owner-created,
  AI-assisted brand image. The project owner controls the resulting asset and authorizes its use,
  modification and distribution with SpaceAgent under the repository MIT License.
- `apps/web/prototypes/liquid-workspace/brand.png` contains the same image as the main 1024-pixel
  brand asset and is retained as the prototype-local copy.
- `apps/web/public/favicon.png` is a resized derivative of the main brand asset and is distributed
  under the same permission.
- Generated prototype exports may embed the same image as a data URL; that embedded copy has the
  same provenance and permission.

## UI and interaction prototypes

`apps/web/prototypes/**` was created by the project owner as SpaceAgent UI and interaction design
work. It is not copied from another software project. The project owner authorizes its use,
modification and distribution with SpaceAgent under the repository MIT License.

The prototypes use repository-local HTML, CSS, JavaScript and the brand image above. Icons are
drawn by repository-local inline SVG path data. Font declarations select operating-system fonts
such as system UI, Iowan Old Style, Palatino, Baskerville, Times New Roman and common CJK system
families; no font binary or web-font file is redistributed. Example URLs, repository names, people
and account data are non-operational interface fixtures, not third-party content feeds.

## Third-party boundary

No ownership is claimed over third-party trademarks, product names, operating-system fonts or any
third-party input material. A future externally sourced image, icon, font, code sample or generated
asset must record its source, license and required attribution before it is added. If provenance or
redistribution permission cannot be demonstrated, the material must be removed or replaced before
release.
